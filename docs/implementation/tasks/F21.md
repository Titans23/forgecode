### Decisions

- 原始包 private-bundle、冲突包 quarantined-bundle、脱敏 artifacts 单独保存；来源声明不是签名。imported_* 独立只读命名空间，永不进入本机调度／费用／策略权威。
- 新增 Main-only prepare_import / prepare_export，使生产私有 RPC 可实际签发 file token；Renderer 不接收路径。原生对话框接线归 F23。
- 记录 requests、annotations、run state、evidence 缺失／改变，保持标准 manifest；解析预算和 unsupported ZIP64 / split 限制见 ADR021。
- durable export intent + atomic no-replace 文件发布支持响应丢失恢复；只读 report/compare 支持导入 run，但 unverified_origin 不能作为可信可比性。
