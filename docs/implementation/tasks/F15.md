### Discoveries

锁定 Electron 44.5.1 的 Windows bootstrap 会将 process.stdin 替换为 EOF。
实际辅助进程曾返回 input 0 bytes；改为直接读取继承的 fd 0 后，真实 safeStorage 加密／重启解密通过。
私有 HTTP 测试还发现 accepted action 不可 UPDATE；migration 005 独立记录测试结果，保留原 action 不变。
慢速连接测试需要有界独立 RPC 派发，否则会延迟撤销／EOF；新增真实 Engine + HTTP 服务验证及时取消。

### Decisions

Main 固定当前 Electron 辅助进程，在私有管道处理系统保护操作，不阻塞 UI；不把 exe 当 Node CLI。
只给该辅助进程传 Linux 桌面会话环境，Engine／任务不继承密钥库通道。
Engine 凭证只在内存，绑定连接 revision 和规范地址；保存、更换地址与网络测试分别使用真实原生确认。
保存和测试 nonce 由 Main 获取并绑定 epoch / revision；三种 provider SDK 显式禁止重定向。
session lock 撤销 Engine key、取消在途工作并清除 Main 内存；不宣称能清零 runtime 中所有副本。
详见 [ADR 015](../adr/015-bound-credentials.md)。F24 / F27 的完整导出验收按依赖继续，不冒充已完成。
