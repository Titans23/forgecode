**实施步骤：**

**新增行为测试：**

- 同一 scripted 输入走 CLI 与服务得到等价工具序列及结束原因。

**完成标准：**

- 应用层无 Electron import、没有第二份 Agent loop。
- 原有离线 CLI 回归不新增失败。

### Discoveries

原 create_runtime 已是各入口共享 composition root，CLI 仅需可选 bindings，避免复制 Runner。ToolExecutor 可在 Journal intent 后注入 backend。部分工具取消时返回未知结果而不抛出取消；adapter 必须停止后续重规划，不能宣称清理已确认。原完成契约拒绝没有外部证据的模型 blocked 声明；测试保留这一行为。

### Decisions

见 ADR 004。strict 默认拒绝未就绪 backend，local-trusted 显式保留；模型注入只在测试使用，执行仍为真实 Harness、工具、Journal、SQLite。服务隔离既有项目权限/扩展配置，凭证不持久化。CLI 与服务共用 OS 工作区锁，保留原 model/provider fork 和原始终态。
