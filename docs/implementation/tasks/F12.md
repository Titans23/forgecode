### Discoveries

- 原 EOF 仅设置 stopping，仍排空任务并等待模型；实际子进程测试先复现，再改为取消队列和在途任务。
- 原只读 execution_cancelled 被 Runner 当普通失败，可能再次请求模型；真实慢工具取消后请求次数现在为 1。
- cancelled 也用于预算／批次未执行项，须按 execution_cancelled 区分；最终回归保留预算和失败后的原有行为。
- Windows Job 关闭不足以提供活动进程核查；新增实际 TerminateJobObject / accounting 查询。
- 旧演示依赖 EOF 排空，改为先显式提交 drain，再丢失 start 响应；实际 bare EOF 取消测试独立保留。
- 刚被强杀的 WAL 库在原测试进程打开曾报 disk I/O error；实际新 Engine 恢复为 reconciling / unknown，F25 继续诊断覆盖。

### Decisions

- ADR 012：UTC + monotonic 期限，生命周期状态 migration 003，原生清理确认独立于任务结果。
- 固定 helper 执行实际 run_command / verify；进程输出保持有界排空，受限 helper 不写项目 .forge archive。
- LocalProcessOwner 为显式 local-trusted 监督，不能作为 SRT native pass。保留服务只接受可信 live close handle。
- PhaseLifecycle 支持 Agent / grader / environment 分期，grader 结果与 cleanup 分开，F20/F21 接入公开评分适配器。
