## Discoveries

基底 913446f；独立 checkout 最初无 dirty 文件。CLI 原先没有接入原生后端；Windows 核心工具仍依赖桌面资产锁。现复用本机已安装绝对工具路径并校验锁定的沙盒 JS 依赖清单。用户必须准备 Python、Node、Git、rg 和平台沙盒前置条件；此轮不做管理员安装。

首轮系统 pytest 临时目录被拒绝访问，记录 219 pass/350 setup errors。改用本任务目录后 567 pass/2 fail：缺可选 Harbor、Windows 长路径 artifact。已按需安装可选评测依赖，并修复长路径读写。两轮旧失败不会覆盖成通过。

原生测试先被安装目录保护边界拒绝；移到本任务 checkout 外部的受控测试目录后暴露 pytest 的 OWNER RIGHTS ACL。只对新建合成测试目录添加当前用户 ACE，不改系统权限。DSH 的共享 workspace SID 会让较宽历史 grant 影响较窄范围；现用规范化的 workspace+write roots 产生 SID，直接使用现有 AclSandbox 接口。

## Decisions

Bundle 是当前入口的依赖组合，Profile 是选择组合的名称；这里只提供实际实现的 terminal/evaluation。SDK 使用 Python API；没有虚构 GUI/Web/SDK 服务或动态插件注册。DSH 设计依据：https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/bundle/README.md。

Journal 是持久会话事实，Conversation/TurnState 是活动执行事实；不从终端文本解析状态。原生初始化失败在模型请求之前拒绝，不回退宿主运行。完整访问需调用方显式选择。文件范围是应用边界；当前 OS 读取和网络继承宿主，写隔离仍为 partial，不能用于声称强隔离官方评测通过。
