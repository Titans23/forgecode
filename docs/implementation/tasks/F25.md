### Discoveries

- Supervisor 超时会删除 request；迟到的合法响应会触发 protocol corruption 并关闭 Engine。需保留有界超时身份、先 action.get 对账，不重新发送 mutation。
- Store 已在重启后转为 reconciling；Journal 投影入口只有正常执行路径，缺少自动补齐已提交记录的启动对账与可读报告。
- mark_indeterminate 可结束工作项；实际 lifecycle 清理 unknown 需要独立执行门禁，不从历史 PID 恢复所有权。
- 已读取规范 6 / 7 / 8 / 15 章及实际 deadline、WAL、Journal、RPC、Bridge 和 Electron 入口。

### Decisions

详见 ADR025。启动只补齐已持久 Journal 投影，不执行模型／工具或使用历史 PID；元数据恢复查询与 UI 明确显示 unknown、缺口与归属范围。Main 超时先查 action.get，有界保存迟到与未确认身份，取消和只读保持可用。
