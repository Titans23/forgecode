### Discoveries

- Tool 卡原来没有 execution ID；Completed 用实际 Recorder branch + call ID 对应，Started 仍明确 null。
- 原工具受控捕获引用未保留；输出改为只保存真实 stdout/stderr 的脱敏私有副本，再按需发布 profile artifact，不开放 raw script / 模型 / 上下文 debug 文件。
- 原受理事件没有 monotonic_ns；新事件记录实际单调边界，历史不伪补；跨 owner epoch 时间不能相减。
- 边界投影在安静 provider 期间可能不更新；补有界 250 ms 定时投影，sequence 不变不重读，失败不重跑工具。
- stale-evidence fixture 的 unittest 会写 __pycache__ 使验证过程内容变化；使用真实 Python -B unittest，再实际执行 invalidate.py，保留生产 stable_during_command 判定。
