# T02 · 单一工作区与文档维护

依赖 F00、T01；对应架构第 0–3 章。日常在 `D:/projects/forgecode` 的 main 开发，保留无关改动、凭据和会话。

README/使用指南说明安装与操作，architecture 说明当前设计，progress 记录当前状态和验证范围。更新或删除过时引用，不新增逐次验收日记。旧 application/engine 仅供显式 RPC 和历史读取；普通 CLI/SDK/benchmark 使用独立内核和 worker。

历史成绩保留来源、版本、协议和限制；冻结实验、测试输入及许可文本不按新产品版本重写。自动报告放在忽略目录 `.local/implementation` 或 CI artifacts。文档变更检查引用和一致性，代码变更验证相关行为后提交、推送并确认实际 CI 状态。
