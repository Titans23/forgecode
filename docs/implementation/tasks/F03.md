### Discoveries

原 SessionJournal 去重集合在 append 前更新，导致失败恢复后同 ID 可跳过 intent/result。先用实际文件障碍和真实命令复现，再把集合更新移到 fsync 后。Windows 的 SQLite context manager 不关闭连接，rb 文件不能 fsync；实际备份测试暴露并修正这两个问题。

### Decisions

新 SQLite 单 writer，实际 OS 锁、WAL/FULL、版本/checksum SQL 迁移；配置快照引用、事务受理、CAS/epoch、事件隔离、原子 artifact/配额。保留旧 Journal，由 metadata source projection 补读，不执行历史命令。见 ADR 003。
