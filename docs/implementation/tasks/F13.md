### Discoveries

- 实际 CJS Main bundle 不能直接使用库内的 import.meta CLI 检测；保留库独立 CLI，桌面 bundle 明确禁用其 CLI 入口。
- 首次真实 GUI 已完成修复，但退出查询漏传 workspace ID，cleanup 为 unknown；修复后以实际状态查询确认，不按 Engine exit 猜测清理。
- Linux venv 固定 Python alias 通常链接到源码根外的可信 runtime；只对该固定 alias 校验真实目标 hash，安装版不允许此例外。
- 实际 OS TCP 表检查 Main/Engine 的所有权；没有用 transport 名称代替监听证明。

### Decisions

- ADR 013：固定资产、私有 stdio、单实例、安全窗口和独立 Engine 生命周期。
- UI 使用实际 DesktopTransport、项目／会话／事件数据；显式 scripted/local-trusted smoke 不提升 native 能力，不产生成绩。
- 直接开发 launcher 不开启 Forge 开发 HTTP server。Main 始终排空有界管道，Renderer reload/crash 不重新受理任务。
- 安装版只接收固定 frozen manifest；缺 F28 组装时阻断，不能使用源码 Python 代替。
