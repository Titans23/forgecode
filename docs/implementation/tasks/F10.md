### Decisions

复用单一 SrtAdapter / 双平台 native canary；Main-only setup 模块真实调用原生 dialog 和固定上游 UAC API，三个严格 action，不接受任意管理员参数。已有安装 / 不可观测共享修复阻断，不 force/uninstall/acl recover。账户/group/credential/marker 全部缺失才允许首次 UAC；不能仅因非提权 cannot-read 拒绝首次 setup。

固定 OS Known Folder worker 跨应用 profile 串行，grants 在 session 期间不变；unknown cleanup 保留 owner / binding marker 阻断重启，不按 PID 清除。目录 deny 采用上游所需尾部 separator，保留 .git worktree 文件。只读授权固定 bundled runtime 子目录；不授权整个开发仓库。见 ADR 010。Main 接入与 GUI 实测由 F13/F14 继续；完整清理 / 崩溃对账由 F12/F25 接续。
