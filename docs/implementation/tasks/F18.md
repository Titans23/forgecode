### Discoveries

Anthropic message_start 的 input usage 和 message_delta 尚不是完整账单；只在实际 stop_reason 后确认完整费用。
官方 OpenAI／Anthropic SDK 的真实 loopback HTTP 测试覆盖重试、缓存、缺 usage 和流中断。
旧嵌入客户端的 SimpleNamespace usage 需要兼容提取；原三参数 ModelUsageUpdate 和 create_runtime 签名保持可用。
上下文压缩报告的 prepared-history 字符数不能作为原始上下文缩小证明；使用真实估算器与精确消息／工具配对指纹。

### Decisions

每个实际 request 在 started 时创建 unknown ledger，冻结受理时的价格；Decimal 计费，后补 usage 更新同一行。
部分 usage 保留原始分量但费用 unknown；未匹配价格不记为零。父子／API retry 分别归因且不重复收费。
默认 metadata；controlled_debug 显式启用后仅保存脱敏、有界本地副本。OTLP 默认关闭，只导出固定 metadata 映射。
复用 SQLite 和已有 Journal；migration 008 备份后回填真实旧请求身份，不猜测旧价格。详见 ADR 018。
