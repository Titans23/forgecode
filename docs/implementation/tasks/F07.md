### Decisions

compile_policy 规范化绝对根、域名、环境白名单、control/.git/.forge 保护，并生成不可变 JSON/hash；服务保存及受理/派发均复核。旧策略规范化或 git 绑定变化时拒绝并要求新 policy，不修改既有事实。能力报告区分布尔支持与 verified/partial/unsupported 证据，未探测默认 unsupported；仅有 true 不能授权强约束。SRT adapter 拒绝严格读取白名单及单靠 config 无法实施的硬资源限制；显式 local-trusted 也不冒充强约束。N08 的词法路径规则不依赖启动 glob，SRT glob 的动态原生效果仍 blocked。详见 ADR 007。
