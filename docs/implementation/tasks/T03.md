# T03 · 轻量可扩展 Agent Harness

依赖 F00、T01；对应架构第 0–3 章。ForgeCode 1.0.0 提供通用 Python 内核，coding Agent 和终端是默认应用，Personal/Robot 等领域通过可选插件扩展同一运行路径。

实施范围：

- core 与 coding 能力分离，工具和领域组件按选择装配，单一模型/工具循环与统一资源所有权。
- 显式受信任插件、自然语言开发、固定独立验收、可复用 Agent 配置与跨环境交付。
- 模型提供方和角色配置、上下文压缩、并发工具、后台命令、同文件修改协调。
- 唯一 Journal 事实源及 ATIF/OpenAI messages JSONL 导出，保留失败、取消、未完成与未知用量。
- 官方镜像、冻结条件、独立 grader 的 benchmark；本地工程夹具与真实模型成绩分开。
- 最小 SDK、可选依赖、公共类型和架构边界检查。蒸馏/训练框架已移除。

权限、文件版本、持久化、取消和清理边界保持。普通 coding 默认宿主 full-access，无独立意图路由、全盘扫描、强制验收或累计 Harness 预算；严格验收与受限执行显式选择。插件宿主执行不宣称恶意代码隔离。

验证覆盖插件加载失败/取消/卸载、会话隔离、恢复、模型切换、源码/依赖绑定、第二环境复验和轨迹导出。使用 `scripts/check_sdk_install.py` 验证无 Node/YAML/模型 SDK 的 core 运行与交付，CI 验证 Windows 和 Linux。缺失平台资源、官方镜像或真实模型实验时保持未验证。

当前状态与提交级验证见 [progress.json](../progress.json)。版本发布统一 Python/npm/workspace 产品版本，独立协议格式版本保持兼容。完整 OS 隔离、管理员配置、付费评测和 registry 发布不因旧计划自动启动。
