### Decisions

17 个真实 handler 才进入 capabilities；剩余契约仅保留 contract_only。控制队列 64、数据队列 8、输入队列 128，单个已写大帧不能抢占；慢 stdout 不阻断任务取消受理。HMAC cursor 绑定 store/profile/scope，ACK 必须对应已发 cursor，快照高水位与事件事务衔接。契约 manifest hash 固定 LF UTF-8，发布资产验证另由 F01 管理。详见 ADR 005。
