## Actual call path

`forge` → `forge.cli:app` / `main` → `create_session_runtime` →
`forge.runtime.factory.create_runtime` constructs the registry, model,
SessionStore, Journal, checkpoints, HookManager and MCPClientManager.
`render_streamed_turn` iterates `Conversation.stream(prompt)` →
`TurnRunner(self).run(prompt)` → request preparation / model stream / sequential
tool execution / completion and message commit.

The existing `ToolExecutor.execute(call, *, checkpoint_id, scope_checker,
operation, result_transformer)` validates input, runs PreToolUse and
BeforeFileEdit hooks, validates changed arguments, checks scope, authorizes,
captures checkpoints, records the Journal intent, executes the registered
operation, then records results and workspace revision. These injection points
are the future HarnessAdapter and sandbox boundaries; the main loop is retained.

`RunCommandTool.execute` delegates to `run_process`; Windows uses WindowsJob and
bounded process-tree termination, Linux uses the Linux worker and process-group
cleanup. Existing command restrictions and path validation are not OS sandbox
isolation. File tools currently accept paths outside the workspace under the
existing CLI contract; future sandbox policies must be explicit per execution.

`SessionJournal.append` obtains `exclusive_append`, `_append_locked` checks the
tail, increments sequence, records UUID/parent UUID, writes JSONL and fsyncs.
SessionStore.open/load restore history; interrupted side effects are inspected,
not blindly replayed. `BudgetedModelClient.stream` records actual network-attempt
boundaries, request snapshots, usage or unknown usage; AnthropicModelClient and
NativeModelClient retain provider-specific behavior. ContextManager owns request
preparation and compaction. Benchmark catalog, Harbor run_turn, summarize_run
and assess_trial already exist and should be wrapped by the evaluation layer.

Actual source lines and signatures are in `code-map.json`, generated by parsing
the files without importing provider factories. `repo-audit.json` captures the
live audit. CLI, benchmark, Feishu gateway, hooks and MCP remain existing entry
points. No JavaScript workspace, desktop app or GitHub CI was present.
