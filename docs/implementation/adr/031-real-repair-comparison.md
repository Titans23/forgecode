# ADR 031 — 真实回归、正式环境与成对复算分别报告

用户已明确授权现有配置中的真实模型，金额预算无上限，本阶段先验收Windows10。授权绑定公开安全记录的canonical hash，JSON标志不能自行授予权限；实际运行仍显式opt-in并共享有限40模型请求／100工具／900秒父预算。

正式Harbor入口对未完成的执行policy、可信授权／逐请求账本绑定、RunSpec和Docker条件返回blocked。Windows额外入口实际调用现有Harness和配置中的provider，在原始任务stubs上工作，并用原始public test bytes在独立进程评分。它不建立native隔离、正式Harbor成绩或完整formal trace，不能解除对应门禁。

只有repair cap0/2允许不同；离线bundle复算校验全部snapshot/hash、计划分母、最后获准attempt及原始requests，禁止best-of，缺grade不生成区间。完整真实批次A3/3、B2/3，无收益声明；统计以三个task cluster探索性报告，费用没有账单／价格来源时unknown。

首批因为客户端资源清单在实验中刷新而source_changed，真实4attempt／33请求保留；另起冻结完整6attempt／50请求，不挑选最好结果。跟踪原始证据摘要与安全索引，源码／资源先构建再冻结，之后仅运行只读核对和验证。
